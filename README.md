# Harshika's Developer Portfolio

A modern, responsive developer portfolio built with React, showcasing projects, skills, and experience in web development and data structures & algorithms.

## Features

- **Responsive Design**: Mobile-friendly layout that works on all devices
- **Project Showcase**: Display of completed projects with descriptions
- **Skills Section**: Comprehensive list of technical skills
- **About Section**: Professional background and experience
- **Contact Form**: Get in touch with contact information
- **Recommendations**: Section for testimonials and recommendations
- **Feedback System**: Collect user feedback
- **GitHub Pages Deployment**: Deployed using GitHub Pages

## Tech Stack

- **Frontend Framework**: React 19.2.4
- **Styling**: CSS
- **Build Tool**: Create React App (react-scripts 5.0.1)
- **Backend**: Firebase 12.11.0
- **Testing**: React Testing Library
- **Deployment**: GitHub Pages

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository

```bash
git clone https://github.com/Harshika-Coder/Portfolio.git
cd Portfolio
```

2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm start
```

The application will open at `http://localhost:3000`

## Available Scripts

- `npm start` - Runs the app in development mode
- `npm build` - Creates a production build
- `npm test` - Runs the test suite
- `npm deploy` - Deploys to GitHub Pages
- `npm eject` - Ejects from Create React App (irreversible)
