# Portfolio

Welcome to my portfolio repository! This project showcases my work in frontend development, UI/UX design, and web application building. It highlights my ability to create modular, visually appealing, and recruiter-friendly projects.

# How to run locally

# Clone the repository
git clone https://github.com/harshika-coder/portfolio.git

# Navigate to project folder
cd portfolio

# Install dependencies
npm install

# Run development server
npm run dev
